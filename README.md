# SyntaxWear - Ecommerce de Tênis e Sneakers

Este projeto é um site de ecommerce focado em tênis e sneakers, com navegação moderna, layout responsivo e organização por categorias, outlet, lojas e área institucional.

## Funcionalidades
- Navegação por categorias (Masculino, Feminino, Outlet)
- Menu de acesso rápido (lojas, sobre, conta, ajuda, carrinho)
- Grid de produtos em destaque
- Seção hero/banner
- Footer completo com newsletter, redes sociais e navegação detalhada

## Como rodar o projeto
1. Clone o repositório:
   ```bash
   git clone https://github.com/SthivemMartins/ecommerce-syntaxwear.git
   ```
2. Abra o arquivo `index.html` em seu navegador.
3. Para desenvolvimento, edite os arquivos na pasta `css/` e `images/` conforme necessário.
